# FocusFlow

FocusFlow is an Android productivity and focus-management application developed in Kotlin for the **Mobile Systems (MobSys 2026)** final project.

## Features

- Task management with categories and completion tracking
- Focus sessions with timer support
- Statistics and custom charts
- Goals and progress tracking
- Calendar overview
- RecyclerView-based task list
- Custom Views drawn with Canvas
- Sensor integration using the accelerometer and light sensor
- Local persistence with SharedPreferences and JSON

## Technical details

- Kotlin
- Android Studio
- Android API 34–36
- RecyclerView
- Intents and Activity result handling
- Custom View / Canvas
- Accelerometer and light sensor
- SharedPreferences / JSON

## Project structure

The repository contains the complete Android Studio project. Local and generated files such as `local.properties`, `.gradle/`, `.idea/`, and `build/` are intentionally excluded.

## Build

Open the project in Android Studio, let Gradle sync, and run the `app` configuration on an Android emulator or device running a supported Android version.
